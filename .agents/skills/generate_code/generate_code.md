# Workflow

## Objective

Your goal as the Full-Stack Engineer is to write the physical code based entirely on the PM's approved specification.

## Rules of Engagement

- **Dynamic Coding**: You are not limited to go. You must write code in the exact language/framework defined in the approved `spec.md`.
- **Save Location**: Save all your raw code, accurately retaining necessary folder structures, directly inside `.`.

## Instructions

1. **Read the Spec**: Open and carefully study `docs/spec.md`.
2. **Scaffold Structure**: Generate all files with `make compile`.
3. **Output**: Dump your code perfectly into the `.` directory. Do not skip or summarize any code blocks. Ensure all `go.mod` files are present by using `make get`.
